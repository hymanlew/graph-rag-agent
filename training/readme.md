# 模型训练模块

## 模块概述

本模块是Graph RAG Agent系统的模型训练核心，负责优化与知识图谱构建和检索相关的基础模型。通过训练，使得模型能够更好地理解和处理项目中的领域知识，提高整个系统的性能和准确性。

## 训练方式

### 1. GRPO训练 (Graph RAG Pre-training Optimization)

训练Qwen2-3B模型，使其更好地适应本项目的实体抽取工作：

- **训练目标**：提高模型识别和抽取华东理工大学相关文档中的实体和关系的能力
- **应用场景**：为`build/build_graph.py`中的知识图谱构建提供高质量的实体和关系抽取
- **优势**：相比通用模型，领域适配后的模型能够更准确地理解和处理教育领域的专业术语和关系类型

### 2. Embedding模型微调

微调embedding模型，使其能够学习项目领域的嵌入特点：

- **数据来源**：`files/`目录下的各种文档（学生手册、规章制度等）
- **训练目标**：优化向量表示，使得语义相似的文本在向量空间中距离更近
- **应用场景**：提升`search/`模块的检索质量和相关性排序
- **优势**：增强领域语义理解能力，提高检索和推理的准确性

## 与项目的整体关系

训练模块在整个Graph RAG Agent系统中扮演着基础支持的角色：

- **输入**：`files/`目录下的原始文档数据
- **输出**：优化后的实体抽取模型和嵌入模型
- **下游模块**：为`build/`（知识图谱构建）、`search/`（搜索）和`agent/`（智能体）模块提供更优质的模型支持
- **迭代优化**：随着系统的使用，可以持续收集反馈数据，进一步优化模型性能

## 训练流程建议

1. 首先准备高质量的标注数据（实体和关系标注）
2. 训练实体抽取模型（GRPO方法）
3. 然后微调embedding模型
4. 在实际应用中评估性能并迭代优化
